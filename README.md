# Vision Math Toolkit

Репозиторий с учебными заданиями по цифровой обработке изображений.

## Стек технологий
* Python
* NumPy
* OpenCV (cv2)
* Scikit-image
* Matplotlib

## Реализованные задачи
* **Task 1 (Basics):** Загрузка изображений, перевод в оттенки серого, работа с цветовыми каналами, расчет и визуализация гистограмм, гамма-коррекция.
* **Task 2 (Filtering):** (добавлю позже при загрузке второго задания)

## Как запустить
1. Установите зависимости: `pip install numpy opencv-python scikit-image matplotlib`
2. Откройте нужный `.ipynb` файл в Jupyter Notebook или Anaconda.
3. Запустите ячейки (Shift + Enter).
